# eSIM Вьетнам

Статический сайт с выбором eSIM для поездок по Вьетнаму.

## Публикация на Vercel

Подключите репозиторий к Vercel. Файлы сайта уже собраны в каталоге `dist`; настройки направляют Vercel на готовые статические страницы. Сборка через npm не требуется.

Включены главная страница, гиды Ханоя, Хошимина, Дананга, Нячанга и Фукуока, фильтры тарифов, инструкция и файлы для поисковых роботов и ИИ.

Для собственного домена укажите его в настройках Vercel. Публикуемые файлы не содержат учётных данных.
